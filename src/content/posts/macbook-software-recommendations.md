> 最后核对日期：2026-08-29。软件功能、价格和系统兼容性可能变化，请以各项目官网为准。

## 开发工具

- **VSCode**：我目前主要使用的代码编辑器
- **Google Chrome**：我主要使用的浏览器，也方便调试网页
- **iTerm2**：我目前常用的 macOS 终端模拟器
- **OrbStack**：我用来管理 Docker 容器，也支持创建 Linux 虚拟机和管理 Kubernetes
- **CC Switch**：灵活切换 Claude/Codex 等编程大模型 API

## AI 助手与知识管理

- **Alma**：强大的 Agent 客户端。我很喜欢把它当作助理
- **Cherry Studio**：功能非常多的大模型客户端，我之前特别喜欢用
- **Obsidian**：笔记软件，插件非常强大。折腾过笔记软件的肯定都用过
- **极速说**：语音编程神器，解放双手

## 系统增强与效率工具

- **Raycast**：我用来替代 Spotlight 的启动器，也会使用它的扩展功能
- **鼠须管 (Rime)**：自定义空间很大的输入法（通过 iCloud 解决跨设备同步）
- **Ice**：极简的顶栏图标管理
- **BetterDisplay**：用于管理外接显示器和 HiDPI 设置
- **Stats**：实时监控 CPU/GPU/网络状态，开源的很好用
- **AlDente**：通过限制充电阈值来延长电池寿命
- **PearCleaner**：轻量、开源的软件卸载残余清理工具。卸载的时候一定要再三确认！

## 办公与影音娱乐

- **OnlyOffice**：兼顾美观与兼容性的开源 Office 方案
- **IINA**：非常强大的播放器
